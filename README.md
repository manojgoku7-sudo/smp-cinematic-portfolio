---

## ✨ Features

✅ **Cinematic Animations** – Smooth, fluid transitions for a premium feel.
✅ **Interactive Map** – Custom `Map.tsx` component for location-based visualizations.
✅ **Responsive Design** – Works seamlessly on desktop, tablet, and mobile.
✅ **Dark/Light Mode** – Theme toggle with `ThemeContext`.
✅ **Modular UI Components** – 40+ reusable components (buttons, dialogs, cards, etc.).
✅ **Error Handling** – Graceful fallbacks with `ErrorBoundary`.
✅ **Performance Optimized** – Lazy loading, efficient bundling with Vite.

## 🛠 Tech Stack

### Frontend
- **Framework**: [React](https://react.dev/) (TypeScript)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: Custom CSS (with `index.css` and `interaction-fluidity.css` for animations)
- **UI Components**: Custom-built (inspired by shadcn/ui)
- **State Management**: React Context API
- **Hooks**: Custom hooks (`useComposition`, `useMobile`, `usePersistFn`)

### Backend *(Optional)*
- **Server**: Node.js (Express/Fastify)
- **API**: RESTful endpoints (e.g., `/api/contact` for form submissions)
- **Database**: *(Future: MongoDB/PostgreSQL for dynamic content)*
