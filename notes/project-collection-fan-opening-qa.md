# Project Collection Fan-Opening — QA Notes

The live desktop preview reports one dedicated fan-opening keyframe per card. Each runs for 0.64 seconds with staggered delays of 0.09, 0.17, 0.25, and 0.33 seconds respectively. The active preview does not request reduced motion; a dedicated reduced-motion rule disables the animation. The final resting fan geometry, labels, and card interactions remain unchanged after the opening sequence.
